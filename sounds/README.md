# Sound samples

Every sound in the game is a recording. These are trimmed, mono MP3 cuts of the originals; `build.sh` embeds them in the page so the game stays a single file. `manifest.json` maps each file to its source and credit, and `gains.json` holds the loudness matching used in the game. The melee roar and marching beds are mixed in the game from these recordings.
