# Sound samples

Trimmed, mono MP3 copies of sounds from three free packs by Kenney (www.kenney.nl), all released under Creative Commons Zero (CC0): Impact Sounds, Interface Sounds and RPG Audio. `manifest.json` maps each file to its original name, and `gains.json` holds the loudness matching applied in the game. `build.sh` embeds them in the page, so the game stays a single file.
